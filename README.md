# ASCII Usagi Rap
INTERIM README

The end goal of this project is to type "usagi" on most terminals and have an ASCII Usagi pop up and do a dance with
his rap playing in the background. The user should be able to end the program prematurely by clicking "q." At the 
end of the program/rap, the final Usagi pose freezes and an encouraging message pops up below, and the terminal can
be used again.

No AI or outsourcing allowed for this one, use yer brain

# Scratch Work

Yeah, we're just gonna take a very finite number of frames and trace them in some software, take
the trace and project it onto the terminal then draw and redraw. The motion is very periodic, 
tracing one frame is VERY easy, and there aren't that many frames. This is also idiotproof (well,
insofar as one does not invent better idiots) unlike the "map colors then use AI segmentation then
{insert 1000 hours of pained automation here}". It's ok to only trace a few frames, get it working,
then trace more for a more convincing animation--that's probably a good idea, actually!
