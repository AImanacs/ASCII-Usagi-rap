# ASCII Usagi Rap
INTERIM README

The end goal of this project is to type "usagi" on most terminals and have an ASCII Usagi pop up and do a dance with
his rap playing in the background. The user should be able to end the program prematurely by clicking "q." At the 
end of the program/rap, the final Usagi pose freezes and an encouraging message pops up below, and the terminal can
be used again.

No AI or outsourcing allowed for this one, use yer brain
